# SEO Setup Guide for Google Indexing

## ✅ What's Already Configured

### 1. **Sitemap.xml** (NEW)
- **File**: `src/app/sitemap.ts`
- **Purpose**: Tells Google about all your pages
- **URL**: `https://anthe.io/sitemap.xml` (auto-generated by Next.js)
- **Pages Included**:
  - Homepage (`/`)
  - Leaderboard (`/leaderboard`)
  - Copytrade (`/copytrade`)
  - Creator/Trader (`/trader`)
  - Feedback (`/feedback`)
  - About (`/about`)

### 2. **Robots.txt**
- **File**: `public/robots.txt`
- **Purpose**: Tells search engines which pages to crawl
- **Status**: ✅ Updated with correct sitemap URL
- **Blocks**: Private pages (auth, settings, dashboard)

### 3. **Structured Data (JSON-LD)** (NEW)
- **Location**: `layout.tsx`
- **Types Added**:
  - **Organization Schema**: Company info, social media links, contact
  - **WebSite Schema**: Site search functionality
- **Purpose**: Helps Google understand your business and show rich results

### 4. **Social Media Links**
- **Location**: Footer component
- **Links**: Twitter, LinkedIn, Telegram, Email
- **SEO Benefit**: Social signals help with ranking

### 5. **Metadata**
- All pages have proper titles, descriptions, Open Graph tags
- Twitter Cards configured
- Canonical URLs set

## 📋 What You Need to Do

### 1. **Submit to Google Search Console**
1. Go to: https://search.google.com/search-console
2. Add your property: `https://anthe.io`
3. Verify ownership (DNS or HTML file)
4. Submit sitemap: `https://anthe.io/sitemap.xml`

### 2. **Submit to Bing Webmaster Tools**
1. Go to: https://www.bing.com/webmasters
2. Add your site
3. Submit sitemap

### 3. **Update Social Media Links in Structured Data**
If your social media URLs change, update them in `layout.tsx`:
```typescript
sameAs: [
  'https://twitter.com/AntheLabs',
  'https://www.linkedin.com/company/anthe-labs/',
  'https://t.me/AntheLabs',
],
```

### 4. **Add More Pages to Sitemap (If Needed)**
Edit `src/app/sitemap.ts` to add dynamic pages like user profiles:
```typescript
// Example: Add user profiles (if you want them indexed)
{
  url: `${baseUrl}/profile/[username]`,
  lastModified: new Date(),
  changeFrequency: 'weekly' as const,
  priority: 0.7,
},
```

### 5. **Monitor Indexing**
- Check Google Search Console regularly
- Look for crawl errors
- Monitor which pages are indexed
- Check search performance
