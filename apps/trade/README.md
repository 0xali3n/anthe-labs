# Trade Service

Trade execution service for copy trading operations.

## Setup

1. Install dependencies:
```bash
pnpm install
```

2. Create `.env` file:
```env
REDIS_HOST=localhost
REDIS_PORT=6379
NODE_ENV=development
```

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Start

```bash
pnpm start
```
